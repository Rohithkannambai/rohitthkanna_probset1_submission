# Ting Ting — Safety Review

MGMT 6110 · Human-AI Collaboration · Problem Set 1

Ting Ting is a fictional front-end prototype for an internal Content Safety Moderator reviewing flagged short-video cases and recording final moderation decisions.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The prototype is front-end only. It uses local fictional data and local media assets; it does not require a backend, API key, model call, or external runtime service.
